HISTORICAL EARTHQUAKE REPLAY

USGS FDSN 기록 · UTC 날짜 기준 · 한 번에 최대 31일

2016년 경주 지진 등 이전 지진의 날짜를 지정해 조회할 수 있습니다.

해석 주의: 지점별 모형값은 원본 실험실의 미검증 거리감쇠식으로 구한 교육용 시연 결과입니다. 실제 관측진도, 공식 예상진도, 해당 시점 발령된 실제 경보를 의미하지 않습니다. 지반 조건·파열 과정·관측 지점 차이를 반영하지 않으며, 지진 발생 후에 공개된 정보를 이용합니다. 관측 기반 진도는 각 기관의 원문을 구분해 확인할 수 있습니다.

DATA AND SAFETY NOTES

데이터 안내

어떤 데이터를 사용하고, 어떤 것은 계산하지 않는지 구분합니다.

KMA · 한국 기상청

기상청 API허브의 getEqkMsg 지진통보문 서비스는 다음 단계에서 연결합니다. 현재는 '연결 대기'이며, 연결 오류를 '지진 0건'으로 처리하지 않습니다.

국내·외 발표정보만 사용하고 지진의 초 단위 조기경보를 직접 수신한다고 주장하지 않습니다.

기상청 API 안내 ↗

JMA · 일본 기상청

다음 단계에서 JMA 공식 웹사이트의 지진정보 목록 JSON을 연결할 예정입니다. 일반적인 공식 개발자 API 계약은 아니며 예고 없이 자료 형식이 바뀔 수 있습니다.

연결 후에는 동일 지진의 여러 발표를 JMA의 사건 ID 기준으로 묶고, 일본 JMA 진도 체계를 유지할 계획입니다.

일본 기상청 지진정보 ↗

USGS · 미국 지질조사국

최근 7일 규모 2.5 이상 GeoJSON 자료를 사용합니다. Railway 서버가 약 60초마다 수집하고, 새로운 결과를 WebSocket으로 전달합니다. 원본 공개 시점은 기관 사정에 따라 달라집니다.

USGS 규모 M, JMA 진도, 기상청 진도는 서로 다른 물리량·체계이므로 동일한 점수처럼 합산하지 않습니다.

USGS 공식 피드 설명 ↗

갱신 주기와 한계

Railway 서버는 USGS 자료를 약 60초마다 확인합니다. 화면은 WebSocket으로 새 자료를 받고, 연결 장애에 대비해 60초마다 HTTP 재조회도 실행합니다. 이것은 지진 발생 후 공개정보의 전달이며 초 단위 조기경보를 보장하지 않습니다.

앱을 닫으면 맞춤 알림이 중단됩니다. 이는 대피를 결정하는 공식 조기경보 시스템이 아닙니다. 중복되는 기관별 발표는 별도의 사건 기록으로 나타날 수 있습니다.

GitHub Pages는 화면만 배포합니다. 인증이 필요한 API 키는 Railway 서버의 환경변수에 보관하고 브라우저로 전송하지 않습니다.
