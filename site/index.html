GEOQUAKE KOREA 데이터 안내

이 화면은 실제 기관에서 발표한 지진 발생정보를 수신한 뒤 표시합니다. 화면 안에서 발생하는 새로운 발표 알림은 정부의 공식 긴급지진속보와 동일하지 않습니다.

한국 기상청(KMA)은 서버의 지진통보 API 조회, 일본 기상청(JMA)은 P2PQuake의 JMA 551 발표 중계, 미국 USGS는 공개 GeoJSON 피드를 사용합니다. 각각 제공 주기와 지연은 다릅니다.

일본에서 관측점별 진도가 제공되면 해당 도도부현의 관측점 최고진도를 표시합니다. 현 전체가 동일한 진도로 흔들렸다는 뜻이 아닙니다. 지역별 관측진도가 없는 경우에는 GEOQUAKE 실험실 v0.8의 거리감쇠 공식을 사용한 교육용 예상진도로 보완합니다. 한국·중국 및 기타 지역의 모형값은 MMI 기반이며, 일본의 모형값은 JMA 형식의 별도 시연 척도입니다. 두 척도를 직접 환산하거나 공식 경보값으로 해석해서는 안 됩니다.

기본 지도: OpenFreeMap(OpenStreetMap 데이터), 대체 지도: OpenStreetMap 표준 타일 · 행정경계: geoBoundaries gbOpen (CC BY 4.0). 공식 발표기관: KMA · P2PQuake · USGS.
