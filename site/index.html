GEOQUAKE KOREA 데이터 안내

이 화면은 실제 기관에서 발표한 지진 발생정보를 수신한 뒤 표시합니다. 화면 안에서 발생하는 새로운 발표 알림은 정부의 공식 긴급지진속보와 동일하지 않습니다.

한국 기상청(KMA)은 서버의 지진통보 API 조회, 일본 기상청(JMA)은 P2PQuake의 JMA 551 발표 중계, 미국 USGS는 공개 GeoJSON 피드를 사용합니다. 각각 제공 주기와 지연은 다릅니다.

일본의 색칠 지도는 각 도도부현 관측점의 보고된 최고진도를 편의상 영역에 표시하는 것으로, 현 전역이 동일한 진도로 흔들렸다는 뜻이 아닙니다. 관측자료가 없으면 색칠하지 않습니다.
